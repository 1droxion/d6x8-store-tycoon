# Device browser beta

This release adds automatic portrait, landscape, desktop and TV control profiles; movable panels; reordered action buttons; saved device preferences; button size, visibility, handedness and look sensitivity; fullscreen where supported; controller/remote menu navigation; and adaptive graphics resolution.

Controls & layout is available from the action menu and phone. Preferences remain on the current browser/device. Rotate or resize to switch layout profiles. Use Auto graphics for adaptive performance. TV play needs a compatible browser with WebGL and a supported keyboard/controller; remote capabilities vary.

Validation: gameplay/engine regression scripts and mocked 3D smoke scenarios passed. Simulated DOM geometry passed at ten viewport sizes from 320×480 to 3840×2160, including drag bounds, persistence, orientation, controller settings and adaptive graphics. These are not real-device browser rendering or performance certifications.

Launch is a public browser beta. Real iOS Safari, Android Chrome and individual TV hardware still need hands-on checks. Older or WebGL-disabled devices may not run. No APK/IPA or store release is included. Online presence requires sign-in; business progress is stored locally. Real ads/payments are not connected.
