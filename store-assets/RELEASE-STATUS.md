# Android release 1.0.1 (2)

- Google Play package: com.d6x8.storetycoon
- Store name: Store Tycoon: City Life
- Category: Simulation
- Intended audience: 16+; optional ads offered only after adult (18+) confirmation
- Monetization: voluntary rewarded ad for 100 fictional store cash; five-minute reward cooldown
- Debug builds use Google test application/ad IDs. Test ads do not earn revenue.
- Release builds use the owner's AdMob application/ad unit IDs.
- No in-app purchases, paid subscriptions, cash-out or multiplayer.
- Public production release is blocked until real-device gameplay/ads testing, genuine gameplay screenshots, support email, consent-message configuration, signing and Play declarations are complete.
- AdMob still needs the published store linked and its readiness/app verification checks completed. App-ads.txt must be served from the developer website root.
